Pinterest API usage

Official API only. Never scraping.

  • PinPulse uses only the official Pinterest API (v5). It does not scrape Pinterest in any form.
  • The app only shows content the API returns under the access granted to it. If Pinterest doesn't return something, PinPulse says so.
  • Connection happens through Pinterest's own OAuth page. PinPulse never sees your password, and tokens are stored encrypted on-device.
  • Pinterest content is cached briefly with expiration and deleted automatically — never warehoused.
  • Pinterest does not endorse PinPulse, and PinPulse is not affiliated with Pinterest. Pins shown belong to their respective creators.
  • You can disconnect Pinterest or delete all local data at any time from Settings.
