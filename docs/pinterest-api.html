Pinterest API Usage

Last updated: September 2026

Official API only

PinPulse uses only the official Pinterest API (v5). It does not scrape Pinterest — no browser automation, no HTML scraping, no undocumented or reverse-engineered endpoints, and no rate-limit workarounds.

What the app accesses

After you authorize PinPulse through Pinterest's OAuth page, the app reads only what the API returns under the access granted to it: your account profile, your own Pins, and your own boards — used to personalize trend recommendations. PinPulse does not access other users' Pins or boards.

When content isn't available

If Pinterest's API does not return something, PinPulse does not work around it. The app shows: "This content isn't available through the Pinterest API with the permissions currently available to this application."

Retention

Pinterest content is cached briefly with expiration and deleted automatically. PinPulse does not build a long-term repository of Pinterest content.

Independence

Pinterest does not endorse PinPulse, and PinPulse is not affiliated with Pinterest. While Pinterest is not connected, PinPulse shows clearly-labeled demo data instead of live Pinterest content.
